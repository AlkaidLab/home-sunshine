# 王冠布局与触控操作

本页面向 **Android Moonlight V+ 12.13.0**。王冠（Crown）保存屏幕按键、快捷动作、触控方式和振动配置；它不是 Sunshine 的主机配置，也不是包含配对身份的完整备份。

## 创建第一套王冠 {#create}

1. 先用 Desktop 确认触控和基础串流正常，在 **设置 → 王冠 → 管理 Crown 配置** 创建一套配置，用游戏名与屏幕方向命名。
2. 选择该配置，再启动目标游戏。从串流中的 **王冠** 入口进入编辑或切换配置。
3. 先摆放少量必要操作，例如移动、视角和确认／返回。按游戏实际输入方式配置，避免同一区域同时承担视角拖动与按钮点击。
4. 保存并退出编辑，分别测试单指、多指和持续按住时的移动与视角。逐个增加按键，不先导入一份无法解释的完整映射。
5. 横竖屏、平板或外接屏切换后，重新检查按键位置与可触达范围，必要时分别保存布局。

王冠入口还可临时隐藏按键。触控失效时先退出编辑、隐藏布局，用普通触控板模式对照，再恢复上一套已验证配置。

## 导入、切换与分享 {#share}

1. 打开 **设置 → 王冠 → 超市王冠**，按游戏名搜索，核对描述、设备和屏幕适配范围，再导入到本地。
2. 回到自己的配置列表选中导入项；进入游戏后从王冠入口切换，测试按钮和多指操作。导入不等于会自动适合你的屏幕。
3. 分享时使用 Crown 的 **导出配置／导出分享包**；接收者使用对应 **导入配置／导入分享包**。旧 `.mdat` 文件走专门的旧版导入入口。
4. 要发布到社区商店，使用应用内 GitHub 授权与投稿流程，提交后等待维护者审核；分享包先检查名称、内容与权限。
5. 修改或合并前先导出自己原来的布局。效果不合适时切回旧布局，确认后再删除不需要的本地配置。

**完整“备份与同步”文件不用于公开分享布局**，因为它可能包含主机配对身份。自己换设备的流程见[备份与换设备](./android.md#备份与换设备)。

## 触控手势与本地键盘 {#gestures}

在 Android V+ 的**触控板模式**串流时，三根手指快速轻点可切换屏幕键盘，双指轻点可发送鼠标右键。先在记事本中测试输入，再用于游戏搜索框；直接触控、分区触控或王冠编辑期间可能走不同手势路径。

Android 13 及以上的 12.13.0 客户端还记录了远程文本框获得焦点时自动唤起本地键盘的能力，需要对应文本输入状态同步。不能自动唤起时，使用串流菜单的屏幕键盘入口；不要把自动唤起与三指手势看成同一功能。

输入异常时，先关掉新增布局或回到触控板对照，确认键盘关闭后按键显示恢复。实体手柄的操作轮盘与统计快捷键见[手柄操作](./controllers.md#shortcuts)。
