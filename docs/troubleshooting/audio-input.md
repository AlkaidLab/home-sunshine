# 声音、麦克风与手柄异常

先在本机确认外设正常，再检查串流。播放声音、回传录音、游戏振动和音频模拟触觉是不同路径，应分别测试。

## 有画面但没有声音

1. 在主机播放音频，确认 Windows 输出设备本身工作。
2. 核对 Sunshine 选择的捕获设备，尤其是刚切换了耳机、HDMI 或虚拟声卡后。
3. 客户端改为立体声 / Opus，检查系统音量、应用静音和实际输出设备。
4. 断开再连接，先验证普通声音，再恢复多声道或其他格式。

只在某种音频格式、蓝牙耳机或功放上无声时，记录该路径，不要先删除主机配置。声音断续同时伴随丢包时，也要看[网络与性能](./performance.md)。

## 麦克风没有声音

沿输入链路逐项确认：

- 客户端明确支持并开启麦克风回传，系统录音权限已授予。
- 串流菜单中的麦克风不是静音状态。
- 主机设备中心的组件和录音设备可用，连接时提供了麦克风通道。
- Windows 录音测试中选对了设备，并能看到电平。
- 游戏或语音软件使用同一个设备，应用本身未静音。

Windows 录音有电平、游戏里没有时，优先检查游戏输入选择与权限。主机完全没有电平时，再查组件、客户端权限和通道。声音回传时出现回声，可以先用耳机测试，区分声学回授与传输异常。

## 手柄无输入或反馈不正确

1. 在客户端系统中测试实体手柄，确认连接和基础按键正常。
2. 在主机设备中心检查当前虚拟手柄组件和所选类型。
3. 改变类型后断开重连，再用主机控制器测试入口或游戏验证。
4. 暂停其他输入映射工具，排除同一手柄被重复模拟。
5. 普通输入正常后，再逐项尝试振动、体感、扳机与触觉。

游戏只支持 Xbox 类型时，先用对应兼容类型测试。高级触觉需要游戏、虚拟设备、客户端和连接方式配合，不能用“普通按钮能用”推断全部反馈也应可用。

### 桌面或菜单自动滚动

先区分摇杆漂移、重复映射与虚拟设备问题。若安装模拟 DS5 组件后才出现，Foundation 当前 FAQ 建议查看最新测试版中的修复；先阅读目标发行说明、备份配置，再决定是否采用 Pre-release。

仍复现时，记录 Windows、Sunshine、客户端及组件版本，以及不连接实体手柄时是否也发生。结合设备中心的组件状态和日志，定位对应的输入路径后再修复。

### 振动效果不对

分别测试游戏原生振动、音频模拟振动和 DualSense 高级反馈。先只开一种，并检查输出选到了手机、手柄还是双路。服务端安装了某个组件，不代表所有客户端都能接收对应反馈。
