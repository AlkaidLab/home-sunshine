# 安装、更新与备份

Foundation Sunshine（基地版）安装在运行游戏和应用的 Windows 电脑上。日常使用优先选择正式发行版的安装程序；便携版适合已有明确部署需求的用户。

## 下载与安装

1. 打开[官网](https://www.alkaidlab.com/#stream-guide)或[正式发行页](https://github.com/AlkaidLab/foundation-sunshine/releases/latest)。
2. 在发行页展开 **Assets**，选择名称以 `WindowsInstaller.exe` 结尾的文件。不要按旧教程固定下载某个历史版本号。
3. 结束现有串流后运行安装程序，阅读安装器对已有配置和组件的处理提示。首次使用优先采用默认路径。
4. 按需要选择组件：虚拟屏用于无物理屏、独立分辨率等场景；麦克风和特殊手柄组件可按需求安装。
5. 安装后打开桌面控制面板，完成向导，确认服务、显卡和显示器状态。

官网提供备用下载渠道时可以使用；仍需核对项目、版本和包名。正式版与 Pre-release 测试版是不同发行通道，先阅读目标版本说明。

## 桌面控制面板负责什么

| 任务 | 入口与用途 |
| --- | --- |
| 首次配置 | 新手向导中选择语言、显卡与显示器 |
| 基地显示器 | 检查 ZakoDisplay 驱动，配置虚拟屏与显示策略 |
| 设备中心 | 检查或安装手柄、麦克风等组件 |
| 应用管理 | 添加、扫描和编辑游戏与应用 |
| 运行与诊断 | 查看服务状态、当前连接、日志和更新 |
| 配套增强 | [HDR 与校准](./hdr.md)、[画质增强](./enhancements.md)、[文件与 USB](./collaboration.md) |
| 自动化与集成 | [超级指令和事件通知](./automation.md)、[AI 与 Web 串流](./integrations.md) |

不同发行版的入口位置可能调整，以安装版本的页面名称为准。驱动安装、本地游戏库扫描等系统操作在 Windows 桌面 GUI 中完成；浏览器管理页不能代替所有本地操作。

新版界面示例见[首次设置向导](../getting-started/index.md#_2-安装并打开-sunshine)、[PIN 配对表单](../getting-started/index.md#_4-添加主机并输入-pin)、[虚拟显示器](./display.md#安装并检查驱动)与[服务端画质设置](./video.md#选择视频编码)。图注标明取图版本；截图中的本机现值不等同于所有设备的推荐配置。

## 使用浏览器管理

需要 WebUI 时，在**主机本机**打开 `https://localhost:47990`。首次按页面提示设置管理用户名和密码，以后用它们登录；管理账号和客户端 PIN 是不同的凭据。

默认自签名证书可能触发浏览器提示。确认访问的是自己这台电脑的准确地址后，再从浏览器高级选项继续。不要为了消除提示而全局关闭浏览器证书校验。

Moonlight 的“添加电脑”应填写主机 IP，不是管理 URL。当前发行版可能限制 WebUI 仅在本机访问；远程管理请先通过已有桌面连接操作主机，不要把管理端口直接映射到公网。

## 更新前备份

1. 记下当前版本和正在使用的组件，结束活动串流。
2. 找到实际使用的配置目录。默认安装通常是 `%ProgramFiles%\Sunshine\config`，自定义安装和启动参数可能改变位置。
3. 备份整个配置目录，而不只是 `sunshine.conf`。应用列表、配对身份和其他配置也需要保留。
4. 把备份放在安装目录以外，记录对应的 Sunshine 版本。

配置备份可能含有配对身份与主机信息，适合自己恢复使用，不应上传到公开反馈区。

## 安装更新并验证

从桌面 GUI 检查更新，或下载目标发行版安装程序。按安装器的实际提示保留配置，不要照旧截图盲选“是／否”；也不要每次更新都先删除虚拟显示器。

更新后确认版本、应用列表、配对设备和组件状态，再从客户端连接 Desktop，分别测试画面、声音和操作。涉及特殊手柄、HDR 或虚拟屏的更新，还应单独验证这些功能。

便携版更新先阅读目标包的说明，不把不同版本的程序和可选组件随意拼在同一个目录。遇到异常先保存日志；需要回退时保留当前配置副本，再使用旧安装包及与其匹配的配置。
