# 找不到主机与配对失败

先确认问题停在哪一步：主机没出现、手动地址也连不上、PIN 不成功，还是配对后应用启动失败。最后一种情况应继续看[黑屏与启动排查](./black-screen.md)。

## 找不到主机

按顺序检查：

1. **服务运行**：主机桌面控制面板显示 Sunshine 正在运行，Windows 没有睡眠。
2. **网络一致**：手机没有切换到移动数据；两端不在隔离的访客网络。
3. **权限**：客户端所需的本地网络权限已允许；曾拒绝过时，到系统设置中检查。
4. **手动添加**：用主机当前活动网卡的 IPv4 地址测试。

在主机运行 `ipconfig`，找到正在使用的以太网或 WLAN 下的 IPv4。不要选到已断开的网卡、无关虚拟网卡或路由器的默认网关。

客户端填主机 IP，例如 `192.168.1.100`，不是 `https://localhost:47990`，也不是客户端自己的地址。这里的示例地址需要换成实际值。

## 手动添加也失败

- 检查主机网络是否允许设备互访，尤其是 AP 隔离、企业策略或不同网段。
- 检查 Windows 防火墙中 Sunshine 的规则是否适用于当前网络配置文件；修正规则，而不是长期关闭整个防火墙。
- 暂停无关 VPN／代理路径做局域网对照，再逐个恢复。
- 如果家用路由器重启后地址改变，重新查 IP；需要固定地址时，可按路由器说明设置 DHCP 地址保留。

如果手动添加成功、自动发现失败，说明发现机制与实际连接路径不同，可以先继续手动连接，不必重装。

## PIN 配对失败

1. 在客户端重新发起配对，保持显示本次 PIN 的界面。
2. 确认打开的是**目标主机**的 Sunshine PIN 码页面。
3. 输入当前显示的 PIN；不要把 WebUI 管理密码填进 PIN 输入框。
4. 检查是否配到了主机上的另一份 Sunshine、其他用户实例或旧服务。

若主机重装、客户端清除数据或换设备后身份变化，可能需要重新配对。先在服务端识别并移除失效的那个设备，再重新添加；不要首先删除所有设备。客户端完整备份也不应被当作跨设备复制配对身份的通用方法。

## 在家能连，在外面连不上 {#remote-access}

家中的局域网 IP 不会自动变成外网地址。先按[远程组网](../server/network.md)确认两端已加入同一可互访网络，再手动添加主机的虚拟 IP。

节点“在线”但不能串流时，还要检查组网访问规则、防火墙和客户端是否实际走这条路径。没有跨网自动发现时，手动添加仍是正常操作。

如果用公网端口映射，则按当前版本和路由器方案核对，不把管理 WebUI 暴露出去。连接后卡顿属于另一类问题，继续看[性能排查](./performance.md)。

## 仍然失败

记录双方版本、连接方式、停在哪一步、原始错误与时间，按[反馈指南](./logs.md)附上脱敏日志。公开反馈中不要贴 PIN、配对证书、组网密钥或完整配置备份。
