# HDR、动态格式与亮度校准

手机、电视和电脑显示器的亮度及格式能力不同。Foundation Sunshine 可以按配对设备分别设置亮度与色彩；先完成[普通 HDR 连接](./video.md#开启-hdr)，再配置动态格式和单设备参数。

## 先确认整条链路

1. 用同一主机、目标屏幕和客户端完成 SDR 连接，并记下分辨率、帧率、编码和捕获方式。
2. 使用虚拟屏时，按[ZakoDisplay 教程](./display.md)确认驱动与 HDR 能力；物理屏则检查 Windows 是否能正确开启 HDR。
3. 确认客户端应用、系统、屏幕和所选解码路径支持目标格式。连接后还需确认实际采用的格式与显示模式。
4. 在客户端开启 HDR，连接后查看实际视频格式、解码器和回退信息。先保持默认亮度，避免同时修改 ICC、动态 HDR 和增强滤镜。

## 选择格式与动态信息 {#hdr-formats}

| 能力 | 配置时关注什么 | 怎么确认 |
| --- | --- | --- |
| HDR10／PQ | 两端的 HDR 视频与显示路径 | 客户端实际格式与系统显示状态 |
| HLG | 客户端和屏幕是否提供 HLG 输出 | 以终端实际呈现路径为准 |
| HDR10+／HDR Vivid | 主机动态信息与客户端接收、输出能力 | 同时核对主机实时状态和客户端格式／回退提示 |
| Dolby Vision | 主机支持 Profile 8.1／8.4 协商与信息注入，终端还需实现对应路径 | 主机协商成功与终端原生显示分别验证 |

在 Sunshine 视频配置中检查 HDR／显示策略及当前版本提供的场景自适应 HDR 选项。开启一项后，用已知内容观察控制面板实时状态，再核对客户端是否实际采用该路径。入口不存在时，先确认主机与桌面控制面板版本是否提供该功能。

**主机有动态信息，不等于终端已经原生显示相同格式。** 尤其是 Android V+ 12.13.0 的 PyroWave 路径，明确不支持 HDR10+／Dolby Vision 动态元数据；应按[实验路径说明](../clients/advanced-video.md#pyrowave)选择兼容路径。

## 为每个配对设备设置亮度 {#per-device}

1. 在主机打开 **PIN 码／客户端配对** 页面，从已配对列表找到当前手机或电视，进入编辑。
2. 在 **HDR 亮度** 选择 **自动（推荐）**，保存后重新连接该设备。
3. 查看运行状态的亮度来源。客户端上报值、安全默认值和手动覆盖不是同一来源；请以本次连接的亮度来源判断设置是否生效。
4. 只有掌握目标屏幕的可靠参数、且自动值确实不合适时，改为 **手动覆盖**。分别填写峰值、最低与全屏亮度，单位为 nits；不要把短时峰值填成持续全屏亮度。
5. 同一内容下比较明暗细节与高光，再断开重连，检查设置是否只作用于对应设备。

例如，分别给“手机”和“客厅电视”保留独立条目；调好电视后，重新连接手机验证它没有沿用电视参数。客户端更换屏幕或显示路径后重新校准。

恢复时把该设备改回 **自动（推荐）** 并重连；不需要删除 PIN 配对或清空全部主机设置。

## 虚拟屏校准与物理屏 ICC {#calibration}

| 场景 | 做法 | 恢复检查 |
| --- | --- | --- |
| ZakoDisplay 虚拟屏 | 先确认当前目标屏，再使用 Windows HDR Calibration；基地虚拟屏可读取校准结果 | 重连后确认亮度来源与目标屏没有选错 |
| 物理显示器 | 默认保留主机本地 HDR 与色彩设置，串流亮度面向客户端 | 连接前后检查本地屏幕设置 |
| 物理屏确有 ICC 兼容需求 | 在对应配对设备的 **物理屏 ICC 覆盖** 中选择已安装的 ICC／ICM | 串流结束后确认原配置恢复 |

ICC 文件选择需要桌面 GUI 提供本机配置文件列表，纯浏览器页面可能提示到 GUI 修改。ICC 覆盖不是所有 HDR 连接的必选项；先使用“系统默认”，有需要时再选择适合目标屏幕的配置文件。

## 验证与回退

用同一段具有暗部和高光的内容，记录主机亮度来源、客户端实际格式和屏幕模式。发灰、黑位抬升、过曝或黑屏时，先撤销新增 ICC／手动亮度／动态选项，再关闭 HDR 回到 SDR 对照。

连接结束后检查物理屏、主屏和原色彩配置。只在某台设备失败时，记录该设备系统、客户端与解码路径，见[显示异常排查](../troubleshooting/black-screen.md)。开发背景见[杜比视界手记](../dolby-vision-dev-journal-zh.md)，具体兼容性以当前客户端、解码路径与设备验证结果为准。
