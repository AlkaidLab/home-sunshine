# 剪贴板、文件共享与 USB

这些能力把客户端与主机的桌面工作流连接起来，需要兼容的主机与客户端，并先完成配对。先查[平台支持](../getting-started/features.md)，再按下面的客户端范围操作。

## 文本与图片剪贴板 {#clipboard}

1. 在主机保持 Foundation 桌面控制面板运行，查看 **剪贴板同步** 工具的状态。若提示本地代理未运行，先重开控制面板；若服务配置强制关闭，先按对应配置恢复允许。
2. Android V+ 在设置中分别开启 **同步剪贴板文本**、**同步剪贴板图片**；PC V+ 使用其剪贴板同步选项。文本与图片同步分别控制，请按需要开启。
3. 开始串流，在客户端复制一段测试文本并粘贴到主机记事本，再从主机复制另一段文字粘贴回客户端。
4. 再用小图片测试。PC V+ 支持双向 PNG 图片同步。Android V+ 12.13.0 请先测试从本机发送图片到主机；主机图片回传 Android 的兼容性尚未确认。

Android 的系统剪贴板访问与应用前后台限制也会影响表现。主机工具显示已激活后仍不同步时，检查客户端类型、复制格式及当前会话；先用纯文本排除图片格式问题。大截图会增加流量，先用小图。

同步的复制内容会离开当前设备，包括密码或验证码。结束工作时关闭不需要的同步选项，重新连接后验证停止同步；同步范围是设备剪贴板，请留意复制内容中的私人信息。

## 共享主机文件夹给 PC V+ {#files}

以下步骤适用于 **Foundation 桌面控制面板 + PC V+**。通过该入口添加的共享文件夹为**只读模式**：客户端可以读取共享文件，不能修改或删除主机文件。

1. 在 Windows 主机的桌面 GUI **设置 → 文件夹共享** 中选择 **添加／选择文件夹**，选一个专门的测试目录，放入小文本文件。
2. 检查列表中的路径、只读状态和已配对设备范围。界面支持单独授权时只开放给需要的设备；若显示“所有已配对设备”，应按这个实际范围判断。
3. PC V+ 连接主机后，从悬浮菜单的 **主机文件** 入口查看共享。跨平台挂载方式受系统与客户端运行环境影响，不要求所有系统出现同一个盘符。
4. 打开或读取测试文件，再试着写入，确认只读限制。主机上未共享的目录不应因此可访问。
5. 在主机列表 **撤销共享**，重新访问或重连确认授权已撤销。撤销访问不会收回客户端之前已经读取或复制的文件。

可选的资源管理器 **通过 Sunshine 共享** 右键入口也创建只读共享。共享请使用“文件夹共享”入口；“文件”配置页用于设置 `apps.json`、证书等路径。共享目录受 symlink／junction 等重解析路径限制，目录不可用时先换普通测试目录。

## 把 Android USB 外设转发到主机 {#usb-forwarding}

本节是 **Android V+ 12.13.0 的实验性 USB 设备转发**。客户端要求 Android 9 或更新与支持的 ARM 架构；ARMv7 设备的兼容性尚未完成实机验证。主机需提供运行时 USB 转发配置及可用的 USB/IP 接收组件。

### 准备主机

1. 保存正在使用 USB 设备的工作并结束活动串流，在桌面 GUI **设备中心 → USB 透传／组件管理** 检查共享 USB 驱动。
2. 按 GUI 提示安装或修复 USB/IP 传输，提示重启时先完成重启，再确认状态就绪。安装过程可能让本机 USB 设备短暂重连。
3. 开启 **允许已配对客户端转发 USB 设备**，保存后按提示重启 Sunshine。WebUI 的输入设置也可能提供同一配置入口。
4. 使用客户端自动发现的转发端口；不要把 Moonlight 转发通道与高级“手动 USB/IP”端口混用。

### 选择设备并验证

1. 将一个普通测试外设接到 Android，确认它在本机可用；先与目标 Sunshine 主机完成配对。
2. 打开客户端的 **USB 外设／USB 共享** 面板，对当前主机启用转发，核对 **共享到** 的主机名称。
3. 选择外设，点 **共享到电脑**，接受 Android 对这台设备的 USB 授权。
4. 等待“连接已建立”，再在 Windows 设备管理器和目标应用确认设备可用；客户端显示成功并不替代主机的实际使用验证。
5. 点 **停止共享**，确认 Windows 中的挂载释放、Android 恢复本机使用，再测试正常结束串流后的恢复。

共享期间设备交由主机使用，不应同时让 Android 本地手柄驱动占用。该版不支持转发蓝牙 USB 适配器；多个相同厂商／产品 ID 的设备还可能受 Android 设备区分限制。出现等待授权、主机不可用或挂载失败时，保留面板错误信息，并检查对应权限与组件状态。

### 手动 USB/IP 是另一条路径

GUI 的高级区域可以挂载可信导出主机明确开放的设备。这条手动连接独立于串流，**不会随串流退出自动释放**，应在主机的“已挂载到本机”中手动释放。标准 USB/IP 本身不提供额外加密与客户端认证，只在可信局域网或受控 VPN 中使用。

共享 USB 驱动也可能供 HD Haptics 或实验性麦克风后端使用。排查时先停止设备共享并保存错误信息，再按组件提示修复，保留其他功能需要的驱动。
