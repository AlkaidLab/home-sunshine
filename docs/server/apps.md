# 添加游戏与应用

Moonlight 中显示的应用来自 Sunshine 的应用列表。先通过 Desktop 连接桌面，再添加游戏，可以把“串流是否正常”和“游戏能否启动”分开检查。

## 先连接 Desktop

客户端已配对主机后，先刷新应用列表，选择 **Desktop**。它让你直接操作主机桌面，不要求为每个游戏建立启动项。

如果内置应用丢失，在 Sunshine **应用** 页查找 **还原内置应用**。这个操作会恢复默认内置项目；已修改这些项目时先备份配置，再决定是否还原。

内置 **Steam Big Picture** 也可作为统一入口。其他游戏管理器可以作为普通应用添加，但不是安装 Sunshine 的必需组件。

## 从桌面 GUI 扫描游戏库

1. 在 Windows 主机打开 Foundation Sunshine 桌面控制面板，进入 **应用**。
2. 选择 **扫描游戏平台库 (Steam/Epic/GOG)**，或在扫描窗口选择本地目录。
3. 检查候选应用、名称和路径，选择需要的项目后添加。
4. 返回客户端刷新应用列表，启动一个游戏测试。

扫描依赖主机上的本地库和文件。浏览器 WebUI 不具备桌面 GUI 的本地扫描能力；只出现一部分游戏时，可以补充手动项目。

## 手动添加

在 **应用 → 添加新应用** 中填写名称和主程序。示例路径如下，需要替换为自己的实际文件：

```text
"D:\My Games\Example\game.exe"
```

路径包含空格时使用英文双引号；程序要求特定工作目录时，一并设置对应目录。依赖 Steam、Epic 等启动器的游戏，先在主机本地确认启动器已登录、游戏可以正常打开，再配置其启动入口。

保存后在客户端刷新应用列表。如果本地启动正常而 Sunshine 启动失败，先核对执行路径、工作目录和运行身份，查看启动时段日志。不要先调整视频码率来解决程序找不到的问题。

## 断开和结束应用

- **断开串流**：停止当前设备的连接，游戏可能继续在主机运行。
- **结束应用**：向服务端请求停止该应用，可能中断游戏进程。

先在游戏里保存进度，再决定退出方式。同一主机有其他连接时，结束应用或改变显示策略可能影响它们；不要把多客户端连接当作多个独立 Windows 用户桌面。

高级的启动前后命令应在普通应用启动正常后再添加。每次只加一项，并测试断开、结束应用和异常退出时是否都能正确恢复。
